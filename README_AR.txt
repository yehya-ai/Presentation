عرض تقديمي عربي احترافي لمشروع نظام إدارة الفعاليات

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح index.html في أي متصفح حديث.
3. استخدم أزرار التنقل أسفل الشاشة أو الأسهم من لوحة المفاتيح.
4. زر "تصدير PDF" يفتح نافذة الطباعة، اختر Save as PDF.

آخر التعديلات:
- إضافة أيقونات Bootstrap واضحة وفخمة بجانب أسماء حالات الاستخدام.
- ضبط المسافات بين الأيقونة والنص ورقم حالة الاستخدام.
- تحسين ألوان الأيقونات لتناسب الخلفية الداكنة.
- تحسين شريحة معمارية النظام مع أيقونات واضحة بجانب كل طبقة.
- إضافة تأثيرات انتقال وحركة احترافية عند التنقل بين الشرائح.
- تحسين تأثيرات الأزرار والكروت عند المرور عليها.

ملاحظة:
الصور التوضيحية موجودة داخل:
assets/images
ويمكن استبدالها لاحقاً بنفس أسماء الملفات حتى تظهر تلقائياً داخل العرض.
